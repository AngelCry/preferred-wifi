# Preferred WiFi

Android-приложение (Android 10+) для предпочтительного выбора сохранённых Wi-Fi сетей, в частности для возврата на 5 ГГц после перехода на 2,4 ГГц.

## Возможности

- Показывает обнаруженные поблизости SSID и ранее выбранные сети.
- Регистрирует выбранные сети через `WifiNetworkSuggestion`. В обычном режиме окончательный выбор остаётся за Android.
- Фоновое наблюдение слушает `SCAN_RESULTS_AVAILABLE_ACTION`: приложение не запускает циклический `startScan()` и не опрашивает Wi-Fi по таймеру.
- При обнаружении выбранной сети сортирует кандидатов по частоте (6/5/2,4 ГГц), затем по уровню сигнала.
- Необязательный Shizuku UserService пытается подключиться к уже сохранённой сети через скрытый `WifiManager.connect(networkId, ...)`. Пароли приложение не читает и не хранит.

## Shizuku

Для режима автоматического переключения:

1. Установить и запустить Shizuku.
2. На Android 11+ можно запустить Shizuku через Wireless debugging; без root запуск обычно нужно повторять после перезагрузки.
3. В Preferred WiFi нажать «Подключить Shizuku» и выдать разрешение.
4. Выбрать нужные сети, нажать «Применить» и включить фоновое наблюдение.

Сеть должна быть заранее сохранена Android на устройстве. Если Shizuku не запущен/не авторизован, приложение только обнаруживает сеть и показывает уведомление.

## Ограничения Android

- `WifiNetworkSuggestion` — предложение системе, а не команда подключения.
- Фоновый монитор не инициирует сканирование. События приходят только после полных Wi-Fi сканов, которые запускает Android или другое приложение; частота таких сканов не гарантирована, особенно в режиме энергосбережения.
- Скрытый Wi-Fi API и доступ к списку сохранённых сетей зависят от версии Android и прошивки производителя. Shizuku запускает helper с shell/root UID, но OEM может ограничить доступ. На конкретном устройстве требуется проверка.
- Foreground Service показывает постоянное уведомление, пока включено наблюдение.
