# Preferred WiFi

Простое Android-приложение (Android 10+) для указания предпочитаемых Wi-Fi сетей системе через `WifiNetworkSuggestion`.

## Как работает
- Показывает доступные рядом сети + ранее выбранные
- Можно отметить сети как предпочитаемые
- При нажатии «Применить» регистрирует их в системе с высоким приоритетом
- Минимум фоновой работы

## Сборка
GitHub Actions автоматически собирает debug APK при пуше в `main`.
Готовый APK можно скачать во вкладке **Actions** → последний workflow → **Artifacts**.
